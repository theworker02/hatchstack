# hatchstack

Hatch validation gates for stack inputs before they hit prod.

**Site:** https://theworker02.github.io/hatchstack/

## Install / run

```bash
git clone https://github.com/theworker02/hatchstack.git
cd hatchstack
node src/cli.js
node --test
```
